# Data Model - CRUD de Empleados

## Entity: Empleado

### Fields
- `clave` (string, required)
  - Primary external identifier.
  - Auto-generated by system in format `EMP-<número>`.
  - Unique across all employees.
- `prefijo` (string, derived/internal)
  - Fixed value `EMP-`.
- `consecutivo` (integer, derived/internal)
  - Positive incremental sequence.
- `nombre` (string, required, max 100)
  - Trim leading/trailing spaces before validation and persistence.
- `dirección` (string, required, max 100)
  - Trim leading/trailing spaces before validation and persistence.
- `teléfono` (string, required, max 100)
  - Trim leading/trailing spaces before validation and persistence.
  - No pattern restriction (not limited to numeric characters).

## Relationships
- No relationships with other entities in current scope.

## Validation Rules
- Reject create requests that include manual `clave` in payload.
- Reject read/update/delete requests with null/empty `clave` or invalid format (must match `EMP-<número>`).
- Reject create/update when `nombre`, `dirección` or `teléfono` exceed 100 chars after trimming.
- Reject update/delete when `clave` does not exist with `404 Not Found`.
- Reject unauthorized access:
  - `401 Unauthorized` when request is unauthenticated.
  - `403 Forbidden` when authenticated user lacks `admin` role.

## State Transitions
- `NON_EXISTENT -> ACTIVE` on successful create.
- `ACTIVE -> ACTIVE` on successful update.
- `ACTIVE -> NON_EXISTENT` on physical delete.
